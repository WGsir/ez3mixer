# EZ3 Mixer

這是一個瀏覽器版音訊 Mixer，可同時加入多個輸入裝置並即時混音播放。

## 功能

- 加入不同輸入裝置作為獨立軌道
- 以單一網址欄位加入一般音訊網址或 YouTube 播放器軌道
- 自動偵測 `setSinkId`：支援時可在每個軌道獨立選擇輸出，不支援時使用統一輸出（系統預設）
- 每個軌道可調整：
  - 音量
  - 左右平衡（Pan）
  - 低通濾波頻率
  - 靜音 / 移除
- Master 音量控制

## 執行方式

建議用本機伺服器開啟（`getUserMedia` 在 `localhost` 可用）：

1. 在專案資料夾執行：

   ```powershell
   python -m http.server 5500
   ```

2. 開啟瀏覽器：

   ```
   http://localhost:5500
   ```

3. 點選「啟用音訊」，允許麥克風權限後即可加入軌道。

## 注意事項

- 監聽輸入裝置時，若使用喇叭外放，可能產生回授（feedback）。
- 建議使用耳機測試。
- YouTube 軌道受限於播放器實作，輸出仍由瀏覽器/系統路由控制。
